# P2.1 shortcut probes

This diagnostic bundle is generated by:

```text
python scripts/run_tier1_p21_shortcut_probe.py --output artifacts/tier1_p21_shortcut_probe --bootstrap-replicates 1000 --seed 7
```

The fresh P2.1 dataset contains 64 questions / 256 question-world groups, with
train/tune/promotion counts of 96/80/80.  Features are frozen from the training
split and use public raw observations only.  The evaluator's branch utilities are
used post-hoc to derive the best-action label and regret; hidden world IDs, family
names, target actions, and branch receipts are not input features.  The removed
`log_confirmation_pass_rate` field is absent from this dataset and is recorded as
omitted in `shortcut_probe_result.json`.

The current environment does not provide scikit-learn.  Results therefore use
explicitly labelled NumPy implementations (`numpy_fallback`, `numpy_cart_ensemble`,
and `numpy_gradient_boosted_trees`).  They are bounded diagnostic baselines, not
formal sklearn claims; `--strict-sklearn` is available when a fail-closed sklearn-only
run is required.

Promotion split results (question-cluster bootstrap, 1000 replicates):

| Probe | Action accuracy | Mean regret | 95% CI for regret |
|---|---:|---:|---:|
| Logistic regression | 0.7375 | 0.064099 | [0.035952, 0.095009] |
| Random forest | 0.5750 | 0.098144 | [0.065053, 0.130840] |
| Gradient boosting | 0.6375 | 0.112272 | [0.083925, 0.137516] |

`run_manifest.json` records source/data digests, runtime versions, and the exact
command.  The bundle is diagnostic-only and does not authorize formal comparison or
model scaling.
